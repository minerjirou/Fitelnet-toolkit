# F221 configuration lifecycle

F221は候補設定 working.cfg と稼働設定 running.cfg と起動設定を区別する。

1. `show working.cfg`、`show running.cfg`、`show startup-config` を取得し、候補に既存の編集がないか確認する。`--backup` は稼働設定だけのバックアップ。
2. 依頼に沿う具体的な設定行を用意し、公式資料の設定モード・対応バージョンを確かめる。
3. `fitelnet-ssh -d NAME --config-file PATH` で候補編集。必要なサブモードのexitをファイルに含める。基本モードへの移行と終了はツールが行う。
4. `show working.cfg` で意図した候補差分を確認する。
5. 反映が承認されている場合に `--commit`。working.cfg全体を反映するので、他者の編集が含まれたら範囲を明らかにする。
6. 別の呼び出しで `show running.cfg` と関連するshowを確認し、接続性やVPN等を検証する。
7. 永続化も依頼されている場合に `--save`。候補設定全体を起動設定へ保存する。稼働設定の単純保存ではない。

`--config-file` だけではcommit/saveしない。`--save` だけではcommitしない。
承認内容に合致すればオプションをまとめられるが、反映の検証後に保存するほうが結果を把握しやすい。
saveにはrollback-configタイマーの停止効果もある。ロールバック保護を使う運用では公式資料に照らして実行タイミングを決める。
エラーで後続設定・反映・保存を停止する。部分的な候補編集を自動的に捨てない。
切断・タイムアウト時は成否不明。再接続して確認し、commit/saveや設定投入を自動再試行しない。
CLIの成功は既知の拒否がなかったことを示すだけで、機能動作の確認を代替しない。
設定応答本文は出さない。必要な確認は対応するshowで行う。
このツールは再起動、対話式鍵入力、SIM切替、汎用運用コマンドの実行に対応しない。
